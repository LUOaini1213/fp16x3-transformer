# Track 3 - Transformer GPU kernel optimization
# On Colab / Kaggle GPU runtimes torch is preinstalled. Reinstall it ONLY if the
# allocated GPU is older than the wheel supports: Kaggle's default API-allocated
# card is a Tesla P100 (sm_60), which torch 2.10+cu128 dropped, so the kernel
# builder in scripts/build_kaggle_selfcontained.py detects the mismatch and
# installs torch 2.5.1+cu121. On a T4 (sm_75) the preinstalled build is fine.
#
# Triton ships with the Linux CUDA build of torch; torch.compile needs it and a
# GPU of compute capability >= 7.0. Nothing else is required at runtime.

# This is the fallback/API floor, not a promise of the measured accelerated path.
# Current normal-import T4 evidence pins torch 2.11.0+cu128 on Linux. The run
# command probes mm(out_dtype=float32), checks CUDA, and reports missing Triton;
# older builds may run the correct FP32 fallback without the headline speedup.
torch>=2.1
